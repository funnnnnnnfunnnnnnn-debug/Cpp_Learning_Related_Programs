# C++ 学习项目集

这个仓库用于记录我在 C++ 学习过程中完成的练习与项目，内容涵盖基础语法、面向对象编程、STL、数据结构、算法以及综合实践。每个项目都保留了实现代码和必要说明，用于整理学习成果、复盘知识点，并持续提升代码设计与问题解决能力。

## 项目内容

| 项目 | 主要内容 | 状态 |
| --- | --- | --- |
| 基础语法练习 | 变量、流程控制、函数、数组与指针 | 持续更新 |
| 面向对象实践 | 类、继承、多态、封装与模板 | 持续更新 |
| STL 练习 | 容器、迭代器、算法与函数对象 | 持续更新 |
| 数据结构与算法 | 链表、栈、队列、树、排序与查找 | 持续更新 |
| 综合项目 | 使用所学知识完成的小型应用 | 持续更新 |

## 技术栈

## 目录说明

每个项目通常包含独立的源代码与说明文档：

```text
.
├── basics/          # C++ 基础练习
├── oop/             # 面向对象编程
├── stl/             # STL 相关练习
├── algorithms/      # 数据结构与算法
└── projects/        # 综合项目
```

> 目录结构会随着学习进度持续调整。

## 编译与运行

以单个源文件为例：

```bash
g++ main.cpp -std=c++17 -O2 -Wall -Wextra -o main
./main
```

使用 CMake 的项目可按以下方式构建：

```bash
cmake -S . -B build
cmake --build build
```
